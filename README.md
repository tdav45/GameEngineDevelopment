A simple 2d game engine.


Controls:


In edit mode
Ctrl + S to save
Ctrl + Q to quit

In run time
WASD to move
Space to jump


GUI details:

In edit mode you can drag bitmaps in from the content window to automatically make game objects which values can be edited in the details panel found from clicking on them in the hierarchy.
You can also play, save, choose a scene, reload the current scene, and quit the game.

In run mode you can stop the game and quit the application. You can also see the frame time details and look at the profiler. You may need to drag the profiler out to see the histogram.
